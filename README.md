A deterministic Pillow illustration sums up five world news stories from 21 November 2026 with original pictograms and readable headlines.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Regenerate with Python 3, Pillow, and the system DejaVu fonts:

```sh
python3 draw.py
```
